# MyViewer

MyViewer is a planned MyOffice remote-support platform for Windows, macOS, Linux, Android and iOS.

The first product milestone targets Windows-to-Windows support with secure sessions, broker/relay infrastructure, unattended access and an operator console. iOS is planned as consent-based screen viewing through ReplayKit.

## Website

The static site lives in web/ and can be hosted on IIS.

## Planned components

- MyViewer Client / Agent
- MyViewer Console
- MyViewer Broker and API
- MyViewer Relay
- MyViewer Mobile

## Brand direction

Dark MyOffice-inspired interface, cyan-to-violet accent gradient, and a screen-outline mark representing secure remote access.
